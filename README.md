# 粉红论坛体生成器

一个纯前端工具，用于生成某粉色论坛风格帖子的静态页面。
包含了作者能想到的所有以提升剧情阅读体验和仿真为目的的细节。
无需服务器或构建工具，数据保存在浏览器本地存储中。
预警⚠️：0人工，纯AI。

## 快速开始

1. 在线使用：访问 [Pink_forum_style_generator](https://imain2026.github.io/Pink_forum_style_generator/)，或下载本仓库后用浏览器打开 `index.html`
2. 点击对应按钮即可开始：修改或新建角色、编辑或添加楼层
3. 完成后导出为静态 HTML 文件（即阅读纯享版）

## 详细说明

### （一）主要页面
主界面模拟经典论坛布局，自上而下为：板块名与板块ID、帖子标题、楼层（每页20层）、分页显示。

底部工具栏：⚙ 配置、↺ 重置、👤 角色管理、＋ 添加楼层、📤 导入导出、📄 静态导出。

### （二）配置编辑

可修改板块名称、板块ID、帖子标题。支持多套主题预设（日间/夜间等），可调整日间主题的色相，保存生效。
> ⚠️重置按钮可恢复默认状态，也会重置所有帖子、角色内容，注意及时导出json⚠️

### （三）角色管理
管理帖子中出现的角色，每个角色拥有独立 ID，可在不同楼层中以原名或别名发言。

1. **新增角色**
输入名称和 8位数字、字母混合的ID（留空自动生成），名称限20字、ID不可重复。名称留空时默认使用 `==`（匿名）。
> 可纯数字/字母。
> ⚠️ID 生成后不可更改⚠️

2. **改名与别名**
可在角色列表中直接改名，确认后同步更新所有使用原名的楼层。别名以英文逗号分隔编辑，发帖时选中别名即可切换。
> 改名仅同步原名字的楼层，使用别名的楼层不受影响
> 每个角色会记住上次使用的别名，下次编辑楼层时自动填入

3. **收藏与排序**
可收藏常用角色，收藏角色在所有排序中自动置顶，并有⭐标识。

4. **头像**
支持上传图片作为头像，未设置时显示默认占位。

5. **搜索**
支持按名称或 ID 搜索，输入时实时筛选。

### （四）楼层编辑

1. **基础编辑**
可新增、编辑、删除任意楼层，每层包含角色身份、楼层号、发布时间和正文内容。
> 删除时引用该层的所有楼层一并删除，后续楼层自动补位并保留跳跃省略
> 发帖时若输入了新别名，会自动追加到该角色的别名列表中

2. **发布时间**
默认填入当前本地时间，可手动修改。

3. **正文内容**
支持 HTML 语法，可实现高亮、删除线、加粗、改变颜色等效果。

4. **内容不可见楼层**
工具栏提供快捷按钮，选中角色后点击即可自动生成对应楼层，模拟被举报/屏蔽/删除的效果。

5. **引用展示**
楼层内的引用块可展开/折叠，顶部只显示引用元信息。

6. **引用回复**
楼层可引用其他楼层，选择引用目标时支持按楼层号或正文内容模糊搜索。
> 编辑被引用楼层时可选是否同步更新引用方中的内容。不同步时引用内容保留旧版，适合制造剧情效果

7. **跳跃楼层**
添加楼层时可指定任意楼层号，中间空缺自动用省略模板填充，用于表现时间推进或略过路人角色的讨论。
> 楼层号需大于现有最大楼层，且不可重复，编辑时会自动校验

8. **楼层缺口**
非连续楼层之间自动显示虚线省略条（如"Nº3 ~ Nº6 已隐藏"），直观呈现楼层跳跃。

### （五）其他功能

- 🌐 **静态页面导出** — 生成独立 HTML 文件，内嵌样式与数据，可直接分享
- 💾 **JSON 导入导出** — 配置、角色、帖子、主题一键导出，支持导入合并
